# 천자문 공부 앱 (1000자)

천자문 1000자를 **카드 뒤집기**와 **퀴즈**로 공부하는 앱입니다.
스마트폰에서 홈 화면에 설치(PWA)해서 오프라인으로도 사용할 수 있습니다.

- 앱 이름: **천자문 공부 — 1000자**
- 배포 주소: `https://johnnie0210.github.io/cheonjamun-study/`

## 주요 기능

- **📇 카드 학습** — 앞면에 한자, 뒷면에 음·뜻(구절은 구절 뜻)·구성 한자
  - 덱 선택: `천자문 구절`(250개) / `개별 한자`(1000자) / `전체`
  - 범위 선택: 구절은 25개씩, 개별 한자는 100자씩
  - 섞기, 좌우 스와이프, 진행률 표시
- **❓ 퀴즈** — 3가지 유형 × 3가지 범위
  - 유형: 한자→음, 한자→뜻, 음→한자
  - 범위: 천자문 구절 / 개별 한자 / 전체
  - 범위 안에서 25구절·100자 단위로 다시 좁혀 출제
  - 문제 수: 10·20·50·100·전체
  - 무작위 / 자주 틀린 것 순서
  - 채점 결과와 오답 목록, "틀린 것만 복습"
  - `한자 → 뜻`은 뜻이 있는 **개별 한자**로 출제됩니다.
- **📖 목록** — 천자문 구절 / 개별 한자 검색·필터 (구절 뜻도 검색에 포함)
- **학습 기록** — 외운 카드·푼 문제·정답률을 기기에 저장

## 파일 구성

```
cheonjamun-app/
├─ index.html              앱 화면
├─ styles.css              스타일
├─ app.js                  앱 로직

├─ 천자문.xlsx             공부할 원본 엑셀 (한자·독음)
├─ 천자문_구절.xlsx        구절 뜻 원본 엑셀
├─ manifest.webmanifest    PWA 설정
├─ sw.js                   서비스 워커 (오프라인)
├─ icons/                  앱 아이콘
├─ .github/workflows/

   └─ package.json
```

## 엑셀만 올리면 자동 반영 (GitHub)

GitHub 저장소에 `천자문.xlsx` 또는 `천자문_구절.xlsx` 파일을 올리거나 교체하면,
GitHub Actions가 자동으로 `data.js`를 다시 만들어 커밋합니다.

1. GitHub 저장소에서 필요한 엑셀 파일을 업로드/교체합니다.
   - `천자문.xlsx` — 한자와 독음
   - `천자문_구절.xlsx` — 250개 구절의 뜻
   - **Add file → Upload files** 로 올리거나, 기존 파일을 열어 **Replace** 합니다.
   - 파일 이름은 반드시 위 이름 그대로 유지해 주세요. (이름이 다르면 자동 반영되지 않습니다.)
2. **Commit changes** 를 누릅니다. (가능하면 `main` 브랜치에 직접 커밋)
3. 저장소의 **Actions** 탭에서 `Update cheonjamun data` 워크플로가 실행됩니다.
4. 완료되면 `data.js`가 자동으로 갱신되고, 잠시 후 사이트에 반영됩니다.
   - 서비스 워커가 **network-first**라서 앱을 다시 열면 최신 내용을 받아옵니다.

> 워크플로가 실패하면 **Actions** 탭에서 로그를 확인해 주세요.
> 저장소 **Settings → Actions → General → Workflow permissions** 가
> **Read and write permissions** 인지도 확인하면 좋습니다.
>
> 저장소가 공개(public)라서 `천자문.xlsx`와 `data.js` 내용도 누구나 볼 수 있습니다.

## PC에서 직접 반영하기

엑셀을 고친 뒤 아래를 실행하면 `data.js`가 다시 만들어집니다.

```powershell
cd build
npm install          # 최초 1회
node parse-xlsx.mjs
```

- 저장소 안의 `../천자문.xlsx`와 `../천자문_구절.xlsx`를 자동으로 찾습니다.
- 다른 경로의 엑셀을 쓰려면 `node parse-xlsx.mjs "..\..\천자문.xlsx" "..\..\천자문_구절.xlsx"`처럼 두 경로를 넘기면 됩니다.

## 엑셀 형식 (`천자문 따라쓰기` 시트)

| A열 | B열 | C~G열 |
|---|---|---|
| 번호(1~1000) | 한자 | 따라쓰기 칸(사용 안 함) |
|  | 다음 행 B열: 훈음(예: `하늘 천`) |  |

- A열에 숫자가 있는 행을 기준으로 B열의 한자를 읽습니다.
- 바로 다음 행의 B열에서 `뜻 + 음`을 읽습니다. (마지막 한 글자가 음)
- 1000자를 4자씩 묶어 250개 구절을 만듭니다.
- 예시)

  | A | B |
  |---|---|
  | 1 | 天 |
  |  | 하늘 천 |
  | 2 | 地 |
  |  | 땅 지 |

## 구절 뜻 엑셀 형식 (`Sheet1`)

| A~D열 | E열 |
|---|---|
| 한자 4자 | 구절 뜻 |
| 다음 행 A~D열: 훈음 |  |

- 구절마다 **2행**을 사용합니다. (첫 행: 한자 + 뜻, 다음 행: 훈음)
- 앱은 **E열의 구절 뜻만** 사용합니다. 한자·독음은 `천자문.xlsx`를 그대로 따릅니다.
- 250개 구절이 천자문 순서대로 있어야 합니다.
- 파서에는 확인된 뜻 보정(#33 대나무 위, #145 진헌공…)이 포함되어 있습니다.
  엑셀에서 해당 문장을 직접 수정하면 엑셀 값이 사용됩니다.
- 예시)

  | A | B | C | D | E |
  |---|---|---|---|---|
  | 天 | 地 | 玄 | 黃 | 하늘은 위에 있으니 그 빛이 검고, 땅은 아래 있으니 그 빛이 누르다. |
  | 하늘 천 | 땅 지 | 검을 현 | 누를 황 |  |

## 배포 (GitHub Pages)

1. GitHub에 저장소를 만들고 이 폴더를 push
2. 저장소 **Settings → Pages** 에서
   - Source: `Deploy from a branch`
   - Branch: `main` / 폴더: `/ (root)`
3. 잠시 후 `https://<아이디>.github.io/<저장소>/` 접속

### 스마트폰에 설치

- **Android(Chrome)**: 주소 접속 → 우측 상단 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **iPhone(Safari)**: 주소 접속 → 공유 버튼 → **홈 화면에 추가**

설치하면 일반 앱처럼 아이콘이 생기고, 오프라인에서도 열립니다.

> **참고**: 서비스 워커가 **network-first** 방식이라, 엑셀을 고쳐 `data.js`를 다시 올리면
> 설치된 앱도 다음 접속 때 최신 내용을 자동으로 받아옵니다. (오프라인이면 캐시된 내용을 사용)
> 그래도 예전 내용이 계속 보이면 `sw.js` 안의 `CACHE` 이름을 `cheonjamun-study-v3`처럼 올려 주세요.
